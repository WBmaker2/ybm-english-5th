# 허락! 골든 벨 게임 앱 디자인

## 목표

초등학교 5학년 영어 YBM 교과서 2단원 수업에서 사용할 수 있는 웹 기반 추첨 게임을 만든다. `pictures` 폴더의 그림 5장을 카드판에 모두 보여 주고, 교사가 버튼을 누를 때마다 아직 뽑히지 않은 카드 중 하나를 랜덤으로 선택해 중앙에 크게 표시한다.

## 핵심 사용자 경험

- 첫 화면에서 그림 카드 5장을 모두 한눈에 확인할 수 있어야 한다.
- 카드판은 3x2 형식으로 보이고, 마지막 1칸은 상태 카드로 사용한다.
- `랜덤 뽑기`를 누르면 현재 라운드에서 아직 뽑히지 않은 카드 중 하나가 중앙에 크게 나타난다.
- 선택된 카드는 애니메이션과 효과음으로 강조된다.
- 이미 뽑힌 카드는 카드판에 그대로 남아 있으며 `뽑힘` 상태와 순서를 표시한다.
- 중앙 큰 카드는 다음 버튼을 누를 때까지 유지된다.
- 다섯 장을 모두 뽑은 뒤 다음 추첨을 누르면 자동으로 새 라운드를 시작한다.
- `초기화` 버튼은 현재 라운드의 상태, 뽑힌 순서, 중앙 선택 카드를 모두 초기 상태로 되돌린다.

## 화면 구조

### 상단 영역

- 게임 제목 `허락! 골든 벨`
- 간단한 사용 안내

### 메인 레이아웃

- 좌측 또는 상단: 3x2 카드판
- 우측 또는 하단: 중앙 강조 영역과 조작 버튼

### 카드판 구성

- 그림 카드 5장
- 상태 카드 1장
  - 현재 라운드 번호
  - 남은 카드 수
  - 마지막으로 뽑힌 카드 번호 또는 상태 메시지

### 중앙 강조 영역

- 선택된 카드를 크게 표시
- 선택 전에는 안내 문구를 노출
- 선택 시 확대, 떠오름, 반짝임 계열 애니메이션 적용

### 조작 버튼

- `랜덤 뽑기`
- `초기화`

## 동작 설계

### 라운드 규칙

- 한 라운드에서는 다섯 장을 중복 없이 한 번씩 모두 뽑는다.
- 내부적으로 현재 라운드용 셔플 순서를 관리한다.
- 다섯 장을 모두 뽑고 난 뒤 다시 `랜덤 뽑기`를 누르면 새 라운드를 시작한다.
- 새 라운드가 시작되면 카드판의 `뽑힘` 상태와 순서 배지는 초기화된다.

### 랜덤 선택

- 피셔-예이츠 셔플 또는 동일한 수준의 공정한 무작위 순서 생성을 사용한다.
- 첫 화면에서 카드 순서는 고정하되, 추첨 순서만 랜덤으로 관리한다.

### 상태 표시

- 뽑힌 카드는 시각적으로 흐리게 하거나 오버레이를 적용한다.
- 뽑힌 순서를 작은 배지로 표시한다.
- 상태 카드는 남은 카드 수와 라운드 정보를 갱신한다.

### 효과음

- 외부 음원 파일 대신 Web Audio API를 사용해 짧은 종소리 계열 효과음을 생성한다.
- 사용자 버튼 클릭 직후 재생되도록 구현해 브라우저 자동재생 제한을 피한다.

## 기술 설계

- 의존성 없는 정적 웹 앱으로 구현한다.
- 브라우저 로직과 테스트 가능한 게임 상태 로직을 분리한다.
- 게임 상태 로직은 ES 모듈로 작성해 Node 내장 테스트 러너에서 검증한다.
- 로컬 실행 편의를 위해 의존성 없는 간단한 Node 정적 서버를 제공한다.

## 테스트 전략

- 순수 게임 상태 모듈에 대해 TDD를 적용한다.
- 최소 검증 항목:
  - 초기 상태 생성
  - 한 라운드 내 중복 없는 추첨
  - 다섯 장을 모두 뽑은 후 다음 추첨 시 새 라운드 시작
  - 초기화 동작
